¡Bienvenido al proyecto Club Tesoros! 🎉

Este es un proyecto completo y funcional para gestionar ferias de pulgas
en tu comunidad. Con un diseño colorido inspirado en Stumble Guys.

🚀 INICIO RÁPIDO:

   1. npm install
   2. cp .env.example .env.local
   3. Configura MONGODB_URI en .env.local
   4. npm run dev
   5. Abre http://localhost:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ CARACTERÍSTICAS:

   ✓ Gestión de ferias de pulgas
   ✓ Catálogo de productos
   ✓ Diseño colorido y divertido
   ✓ Animaciones suaves
   ✓ Responsive (móvil, tablet, desktop)
   ✓ API REST completa
   ✓ MongoDB Atlas
   ✓ TypeScript
   ✓ Next.js 16

🎨 TECNOLOGÍAS:

   Backend:   Next.js API Routes, MongoDB, Mongoose
   Deploy:    Vercel (recomendado)
